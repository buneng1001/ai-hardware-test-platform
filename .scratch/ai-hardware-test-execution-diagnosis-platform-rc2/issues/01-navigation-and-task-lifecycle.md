# 01 — 重做页面导航与采集任务生命周期管理

**What to build:** 让测试工程师通过清晰的页面或标签管理合成型和导入型采集任务，查看任务与运行关系，并安全删除或归档任务。

**Blocked by:** None — can start immediately

**Status:** resolved
**Version:** v0.1.0-rc.2

- [x] 提供仪表盘、新建任务、根据导入生成、已保存任务和运行详情等明确页面或标签，设置从顶栏进入。
- [x] 已保存任务支持来源、执行状态、归档状态、筛选和每页最多 10 条的分页展示。
- [x] 任务名称、任务内执行序号、内部运行 ID、队列位置和阶段状态在对应读模型中可观察。
- [x] 合成型和导入型任务统一遵守“未执行可删除、已有运行只能归档”，删除不得级联删除运行或证据。
- [x] 页面和公开 API 测试覆盖导航、列表、删除/归档边界、队列说明和运行详情切换。

## Answer

- 实现顶栏标签导航、根据导入生成占位页、设置入口和运行详情入口；默认保留工作区全览以兼容 RC1 页面测试，点击标签后切换到对应内容。
- 新增 `/api/collection-tasks/saved` 分页读模型，支持来源、执行状态和归档状态筛选，服务端强制每页最多 10 条；前端提供筛选控件及上一页/下一页。
- 新增删除与归档 API。无运行记录任务可删除；有运行记录任务删除返回 409 且只能归档；归档不触碰运行和证据。
- 运行读模型新增任务名称、任务内执行序号、队列位置和阶段状态；数据库 v11 迁移会为历史运行按任务和运行 ID 回填执行序号。
- 验证证据：后端 `101 passed`；前端 `26 passed`；前端 typecheck、Prettier 和本次改动文件 Ruff check/format check 通过。完整 Ruff format check 仍会报告既有的 `scripts/run_ticket20_acceptance.py` 格式差异，本 ticket 未修改该文件。
