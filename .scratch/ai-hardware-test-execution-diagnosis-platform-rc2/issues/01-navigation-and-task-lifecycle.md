# 01 — 重做页面导航与采集任务生命周期管理

**What to build:** 让测试工程师通过清晰的页面或标签管理合成型和导入型采集任务，查看任务与运行关系，并安全删除或归档任务。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent
**Version:** v0.1.0-rc.2

- [ ] 提供仪表盘、新建任务、根据导入生成、已保存任务和运行详情等明确页面或标签，设置从顶栏进入。
- [ ] 已保存任务支持来源、执行状态、归档状态、筛选和每页最多 10 条的分页展示。
- [ ] 任务名称、任务内执行序号、内部运行 ID、队列位置和阶段状态在对应读模型中可观察。
- [ ] 合成型和导入型任务统一遵守“未执行可删除、已有运行只能归档”，删除不得级联删除运行或证据。
- [ ] 页面和公开 API 测试覆盖导航、列表、删除/归档边界、队列说明和运行详情切换。
