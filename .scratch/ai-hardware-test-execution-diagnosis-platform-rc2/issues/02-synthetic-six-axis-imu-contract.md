# 02 — 升级合成数据与六轴 IMU 契约

**What to build:** 让测试工程师通过新建任务页面生成带完整时间契约、视频码率和六轴 IMU 的可重复合成数据。

**Blocked by:** 01 — 重做页面导航与采集任务生命周期管理

**Status:** resolved
**Version:** v0.1.0-rc.2

- [x] 快速模式使用 100Hz IMU，自定义模式仍允许 50、100、200、500Hz。
- [x] 合成 IMU 包含三轴加速度和三轴角速度，单位、坐标系、字段顺序和精度具有稳定契约。
- [x] 视频配置支持已定义的码率单位、范围、预设值以及 CBR/VBR 语义，并进入配置快照、生成和检查。
- [x] 合成视频和 IMU 同时保留原始设备时间与相对时间，固定随机种子仍能复现等价产物。
- [x] 公开 API、生成运行和前端表单测试覆盖正常、边界、非法输入和六轴字段验证。

## Answer

- 快速预设固定为 100Hz；自定义模式保留 50、100、200、500Hz。
- 新增六轴 IMU 稳定字段契约：原始设备 ns 时间、相对秒时间、三轴加速度（m/s²）、三轴角速度（rad/s）、固定坐标系、字段顺序和 6 位精度。
- 新增视频码率 `256～50000 kbps`、2500kbps 默认预设及 CBR/VBR 语义；码率进入配置快照、FFmpeg 生成参数和 `video_bitrate` 检查。
- 生成 metadata 保留视频容器 PTS、视频起始原始设备时间、帧号起点及 IMU 时间字段契约；原始时间不被相对时间覆盖。
- 固定随机种子下，IMU、故障真值和生成指纹在重复运行中保持一致；前端自定义表单展示码率边界和模式。
- 验证证据：后端完整测试 `107 passed`；前端完整测试 `26 passed`，`pnpm run build`、typecheck、Prettier 和 Ruff check 通过。
