# 02 — 升级合成数据与六轴 IMU 契约

**What to build:** 让测试工程师通过新建任务页面生成带完整时间契约、视频码率和六轴 IMU 的可重复合成数据。

**Blocked by:** 01 — 重做页面导航与采集任务生命周期管理

**Status:** ready-for-agent
**Version:** v0.1.0-rc.2

- [ ] 快速模式使用 100Hz IMU，自定义模式仍允许 50、100、200、500Hz。
- [ ] 合成 IMU 包含三轴加速度和三轴角速度，单位、坐标系、字段顺序和精度具有稳定契约。
- [ ] 视频配置支持已定义的码率单位、范围、预设值以及 CBR/VBR 语义，并进入配置快照、生成和检查。
- [ ] 合成视频和 IMU 同时保留原始设备时间与相对时间，固定随机种子仍能复现等价产物。
- [ ] 公开 API、生成运行和前端表单测试覆盖正常、边界、非法输入和六轴字段验证。
