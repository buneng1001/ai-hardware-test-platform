# 03 — 实现独立时间对齐与逐帧视频—IMU 映射

**What to build:** 让测试工程师在不损坏原始时间证据的前提下，复核每一路视频帧与对齐后 IMU 样本之间的实际时间关系。

**Blocked by:** 02 — 升级合成数据与六轴 IMU 契约

**Status:** ready-for-agent
**Version:** v0.1.0-rc.2

- [ ] 对齐时间作为独立派生结果保存，不覆盖视频或 IMU 的原始设备时间和相对时间。
- [ ] 保留参考时钟、对齐方法、参数、对齐前指标和对齐后残差。
- [ ] 对每一路视频的每一帧，从完成时钟对齐的 IMU 序列中选择时间差最小的样本。
- [ ] 独立映射产物记录视频通道、帧号、双方原始/相对/对齐时间、IMU 样本序号、真实时间差、容差和匹配状态。
- [ ] 运行详情、报告和证据包可引用映射产物，并覆盖不同采样率、无匹配和边界情况的公开 API 测试。
