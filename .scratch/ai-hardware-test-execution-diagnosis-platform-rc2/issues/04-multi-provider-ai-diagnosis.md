# 04 — 接入三服务商 AI 诊断与安全降级

**What to build:** 让测试工程师安全选择硅基流动、DeepSeek 或 Kimi 进行独立 AI 诊断，同时在服务不可用时不影响测试执行和原始报告。

**Blocked by:** 01 — 重做页面导航与采集任务生命周期管理

**Status:** ready-for-agent
**Version:** v0.1.0-rc.2

- [ ] 三个服务商分别隔离凭据、端点、推荐模型目录和自定义模型，错误不得静默换模型或跨服务商发送密钥。
- [ ] 设置页和连接测试显示服务商、模型、请求中、成功、失败和可重试状态，并防止重复提交。
- [ ] AI Key 只保留在当前会话内存；接口、数据库、日志、报告和证据包不返回或保存 Key。
- [ ] 诊断接受明确允许的结构化包装，内部异常转换为用户可读错误码和摘要，真实响应回放纳入回归测试。
- [ ] 仅对超时、限流和临时服务错误自动重试且最多两次；模型失败不改变运行状态，并允许人工重试。
- [ ] 前后端公开行为测试覆盖三服务商隔离、Mock、凭据安全、失败降级和诊断归属。
