# 05 — 实现实际测试 ZIP 导入与安全校验

**What to build:** 让测试工程师在独立的“根据导入生成”页面上传一个实际测试 ZIP，经分层安全和兼容性校验后创建尚未执行的导入型采集任务。

**Blocked by:** 01 — 重做页面导航与采集任务生命周期管理；02 — 升级合成数据与六轴 IMU 契约

**Status:** ready-for-agent
**Version:** v0.1.0-rc.2

- [ ] 一次只接受一个 ZIP；页面提供导入、校验、转为标准格式和加入任务列表四个按钮，并按状态启用。
- [ ] ZIP 必须包含 manifest、至少一路 1～4 路 H.264 MP4/MKV 视频和一个最低 100Hz 的六轴 IMU 文件。
- [ ] manifest 声明通道、帧率、分辨率、码率、时间来源和每路视频的起始原始设备时间。
- [ ] 校验区分安全/结构校验与平台兼容性校验，状态为通过、不通过或非标准但可转换；错误禁止入库，警告持续可见。
- [ ] 实现哈希去重、同名异哈希区分、权限确认、Git 忽略隔离区、原子入库和 24 小时临时保留。
- [ ] 执行 2GiB ZIP、10GiB 解压、100 文件、5GiB 单文件、100:1 压缩比、路径穿越、加密压缩和 ZIP 炸弹边界检查。
- [ ] 缺少可选状态/日志属于警告；实际数据不得伪造 fault_truth.json；转换入口首版只显示开发中提示。
- [ ] 公开 API 和前端测试覆盖正常、损坏、恶意、重复、边界和重复请求场景。
