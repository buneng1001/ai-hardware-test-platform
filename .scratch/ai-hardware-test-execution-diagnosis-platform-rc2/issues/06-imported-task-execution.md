# 06 — 让导入型任务进入统一运行与分析链路

**What to build:** 让测试工程师在导入任务入列表后手工配置并启动运行，获得适用的确定性检查、时间分析、人工结果、报告和独立诊断。

**Blocked by:** 03 — 实现独立时间对齐与逐帧视频—IMU 映射；05 — 实现实际测试 ZIP 导入与安全校验

**Status:** ready-for-agent
**Version:** v0.1.0-rc.2

- [ ] 导入任务创建后不自动运行，测试工程师必须配置参考时钟、判定模式和阈值后手工启动。
- [ ] 导入型运行跳过合成数据生成和故障真值，自动执行所有适用的确定性检查。
- [ ] 缺少可选证据时对应检查为未执行，而不是通过或失败；导入型运行不产生故障真值对照指标。
- [ ] 导入型运行保留原始输入不可变性，并产生独立的检查、对齐、人工结果、报告和诊断派生结果。
- [ ] 运行详情可观察导入来源、校验警告、阶段、取消、异常中断、复测和任务生命周期限制。
- [ ] 公开 API 集成测试覆盖手工启动、正常完成、缺证据警告、失败降级、取消和历史证据保护。
