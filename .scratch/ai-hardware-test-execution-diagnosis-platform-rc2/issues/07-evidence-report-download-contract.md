# 07 — 完善报告、证据 ZIP、原始视频下载和人工结果契约

**What to build:** 让测试工程师获得可独立复查、边界清晰且可回导的报告与证据产物，同时区分完整原始视频和受限证据样本。

**Blocked by:** 03 — 实现独立时间对齐与逐帧视频—IMU 映射；06 — 让导入型任务进入统一运行与分析链路

**Status:** ready-for-agent
**Version:** v0.1.0-rc.2

- [ ] 原始视频提供独立下载；证据 ZIP 默认排除原始视频，仅允许显式加入受限小样。
- [ ] ZIP 包含报告、结构化检查、人工结果、日志、缩略图、清单、哈希和逐帧映射，并记录导出时间。
- [ ] ZIP 按下载时当前状态生成，人工结果或诊断变化后能提示重新导出。
- [ ] 面向 Excel 的 CSV 使用 UTF-8 BOM；人工结果导入与导出契约一致，或提供明确独立模板。
- [ ] 报告同时展示确定性检测结果和人工检查结果，不互相覆盖；缺少可选证据明确展示未执行。
- [ ] 公开 API 测试覆盖默认排除、受限小样、敏感字段、哈希清单、可回导和失败不留半成品。
