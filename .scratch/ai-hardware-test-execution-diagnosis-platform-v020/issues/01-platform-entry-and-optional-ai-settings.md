# 01 — 平台入口与可选 AI 配置

**What to build:** 为测试工程师提供简洁的平台首页，以及可选的模型配置、连接测试和“暂不配置”入口。配置是否存在都不能阻塞项目管理及后续确定性测试流程；本 ticket 不建设 Skill 运行时或四类能力注册中心。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

**当前前端 Demo 对应页面：** 首页 AI 配置卡；现有 `SettingsPanel` 连接测试能力。

- [ ] AI 配置持久化保存，应用重启后能够恢复，密钥不通过读取接口明文返回。
- [ ] 用户可以测试模型连接，也可以明确选择暂不配置并进入项目列表。
- [ ] 无密钥、连接失败或模型服务不可用时，项目管理和确定性测试能力不受影响。
- [ ] 首页不展示项目趋势或运行统计，只展示平台定位、基础能力和进入平台的入口。
- [ ] 数据库迁移、设置接口、首页交互和敏感字段处理均有自动化测试。
- [ ] 配置快照包含 provider、Endpoint、模型、密钥来源和网络方式；模型目录、连接测试与业务运行使用同一份快照（见 AI 接入护栏）。
- [ ] 模型目录、已验证状态和当前选择分别保存；切换 provider、Endpoint、密钥来源或网络方式后，旧验证状态立即失效并提示重新测试。
- [ ] 连接测试使用独立短超时，错误能区分网络、代理、鉴权、权限、模型 ID、限流和服务商错误，且不泄露密钥。
- [ ] 当前选择不在新发现的模型列表中时给出明确提示，不静默改选其他模型。
