# 01 — 平台入口与可选 AI 配置

**What to build:** 为测试工程师提供简洁的平台首页，以及可选的模型配置入口、连接测试和"暂不配置"入口。配置是否存在都不能阻塞项目管理及后续确定性测试流程；本 ticket 不建设 Skill 运行时或四类能力注册中心。

配置的持久化、快照字段、验证失效和迁移已移交 15 号任务，分层超时与错误分类移交 16 号任务；本 ticket 只负责入口与降级表现。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

**当前前端 Demo 对应页面：** 首页 AI 配置卡；现有 `SettingsPanel` 连接测试能力。

- [x] 用户可以测试模型连接，也可以明确选择暂不配置并进入项目列表。
- [x] 无密钥、连接失败或模型服务不可用时，项目管理和确定性测试能力不受影响。
- [x] 首页不展示项目趋势或运行统计，只展示平台定位、基础能力和进入平台的入口。
- [x] 未启用持久化配置时，界面明确说明临时密钥仅在本次会话有效，不暗示已保存；15 号任务接入持久化后再改为持久化状态提示。
- [x] 首页交互与敏感字段处理有自动化测试，确认密钥不进入 URL、响应、日志和数据库。
