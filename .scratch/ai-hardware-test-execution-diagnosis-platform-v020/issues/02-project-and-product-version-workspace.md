# 02 — 建立项目与产品版本工作区

**What to build:** 让测试工程师创建和查找长期项目，在项目中管理 Beta 产品版本，并以选中的项目和产品版本作为后续测试资产、记录和报告的稳定上下文。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

**当前前端 Demo 对应页面：** “项目列表”；“版本与趋势”；IRIS 项目卡和 EVT1 工作区。

- [ ] 项目和产品版本分别持久化，并建立“项目包含多个产品版本”的明确关系。
- [ ] 支持项目创建、搜索、排序和打开；删除前展示产品版本及已有资产的影响范围。
- [ ] 支持产品版本创建、编辑和打开；新建版本不强制填写测试范围或阶段目标。
- [ ] 删除产品版本前展示测试资产、测试组、记录和在线报告的影响范围。
- [ ] 项目详情在无最终报告时展示正确的趋势空状态。
- [ ] 数据库关系、项目/版本接口、页面导航和主要用户交互均有自动化测试。
