# 05 — 完成自动化用例编辑、反馈、校验与转换历史

**What to build:** 让测试工程师把规则候选整理成可执行资产，包括编辑、新增、删除、可选 AI 反馈、确定性校验和转换历史；没有可用 AI 适配器时，人工编辑与校验仍完整可用。

**Blocked by:** 04 — 通过规则服务生成自动化用例候选。

**Status:** ready-for-agent

**当前前端 Demo 对应页面：** “自动化用例表”；AI 反馈列；“提交修改并重新生成”；“校验自动化用例”。

- [ ] 用户可编辑标题、输入、操作步骤和预期结果，也可删除当前自动化资产而不影响历史快照。
- [ ] 用户可新增自动化用例，自动化编号由系统生成，并且必须选择一个有效来源编号。
- [ ] 新增、编辑、删除或重新生成后，相关内容立即变为“未校验”。
- [ ] AI 反馈使用独立字段；无适配器时明确显示不可用并保留用户输入，不伪造 AI 返回。
- [ ] 只有反馈被可用适配器成功接收后才清空输入；人工编辑不因 AI 不可用而丢失。
- [ ] 校验覆盖编号、来源和必填内容，未通过校验的自动化用例不能加入测试组或执行。
- [ ] 转换历史能够查看原始内容、初始规则转换、用户修改和反馈处理状态。
- [ ] 数据变更、反馈接口、校验接口、页面离开提示和前后端交互均有自动化测试。
