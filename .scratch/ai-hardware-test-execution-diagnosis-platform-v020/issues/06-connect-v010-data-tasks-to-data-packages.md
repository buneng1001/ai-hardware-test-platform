# 06 — 将 v0.1.0 数据任务接入平台级数据包资产

**What to build:** 保留现有采集任务作为数据生成、导入和检查任务，并把合规结果登记为可复用、可版本化的数据包。测试工程师可以查看、筛选和管理数据包，但未经校验的数据不能用于测试组。

**Blocked by:** 02 — 建立项目与产品版本工作区。

**Status:** ready-for-agent

**当前前端 Demo 对应页面：** “测试数据”；数据卡片；现有新建任务、导入任务、已保存任务和运行详情。

- [x] 数据包持久化记录来源任务、来源类型、版本或指纹、生成时间和校验状态。
- [x] 数据包详情展示文件、通道、时间戳、完整性以及正常/故障属性。
- [x] 支持生成/导入、正常/故障和指定故障类型筛选。
- [x] 同一数据任务产生新结果时创建新数据包而不覆盖旧包，并提示输入源已有更新。
- [x] 更新提示可以推荐最新结果，但不自动替换已有关联，旧数据包仍可用于复现。
- [x] 删除数据包前展示关联测试组、用例和记录的影响范围。
- [x] v0.1.0 运行记录继续作为数据任务运行记录，不被改名或直接复用为 v0.2.0 自动化执行记录。
- [x] 数据库迁移、数据包接口、测试数据页面和 v0.1.0 兼容性回归均有自动化测试。
