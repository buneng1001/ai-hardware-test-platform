# 07 — 创建测试组并分配用例与数据包

**What to build:** 让测试工程师在产品版本内创建多个测试组，维护人工与自动化用例范围，并为自动化用例批量或逐条关联已经校验的数据包。

**Blocked by:** 05 — 完成自动化用例编辑、反馈、校验与转换历史；06 — 将 v0.1.0 数据任务接入平台级数据包资产。

**Status:** ready-for-agent

**当前前端 Demo 对应页面：** “自动化测试设置”列表与详情；正式实现统一使用“测试组”名称。

- [ ] 创建测试组时只要求基本信息，并可带入当前项目/版本的待加入清单。
- [ ] 测试组支持编辑、搜索、排序、分页、隐藏、恢复显示和确认影响后删除。
- [ ] 支持添加、移除和排序原始/自动化用例；从组内移除不删除平台级用例。
- [ ] 只有校验通过的自动化用例可以进入可执行范围。
- [ ] 数据包与自动化用例为多对多关系，支持批量关联和表格内逐条切换或取消。
- [ ] 同一数据包可以被多个用例和测试组复用，取消一条关联不影响其他关系。
- [ ] 软件版本不一致、数据包未校验和输入源更新均有明确提示，不自动替换用户选择。
- [ ] 数据库关系、测试组接口、详情表格和关联边界均有自动化测试。
