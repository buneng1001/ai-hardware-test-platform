# 08 — 执行数据驱动模拟并保存不可覆盖快照

**What to build:** 从测试组启动数据驱动模拟，先执行可修复的准备检查，检查通过后再创建正式自动化执行记录和不可覆盖快照，并运行确定性数据检查。

**Blocked by:** 07 — 创建测试组并分配用例与数据包。

**Status:** ready-for-agent

**当前前端 Demo 对应页面：** 测试组详情的“执行自动化测试”；“执行与结果”中的自动化执行卡片。

- [x] v0.2.0 只提供数据驱动模拟，不展示设备状态机、ADB、HTTP、Shell 或真实设备连接能力。
- [x] 准备检查验证测试组、已校验自动化用例、数据包存在性和格式。
- [x] 检查失败显示错误编码、失败对象、实际值、期望值、修复建议和可操作入口。
- [x] 重新检查或取消准备流程不会创建正式执行记录。
- [x] 开始执行时生成执行编号、时间以及不可覆盖的测试组、用例、配置和数据包快照。
- [x] 再次执行、执行失败、取消或中断均产生新记录，不覆盖旧记录。
- [x] 用例结果支持通过、失败、阻塞和未执行；故障数据导致预期检查不满足时记为失败。
- [x] “已完成”表示所有计划项完成尝试，不要求所有结果通过。
- [x] 数据库、准备与执行接口、状态刷新页面、快照不可变性和确定性执行均有自动化测试。
