# 09 — 独立录入并维护人工测试结果

**What to build:** 让测试工程师在项目、产品版本和测试组上下文中独立录入人工结果，支持分批保存、恢复编辑、删除和附件，不受自动化执行进度约束。

**Blocked by:** 07 — 创建测试组并分配用例与数据包。

**Status:** ready-for-agent

**当前前端 Demo 对应页面：** 独立“人工测试结果”页面；“执行与结果”中的人工记录入口。

- [ ] 页面只显示测试组中的人工用例和混合用例，不显示纯自动化用例。
- [ ] 人工结果持久化绑定项目、产品版本、测试组、来源用例和记录批次。
- [ ] 支持逐行或批量保存，并在关闭后重新打开页面时恢复已保存内容。
- [ ] 支持通过、失败、阻塞和未执行；未填写项在报告输入中确定性表达为未执行。
- [ ] 人工结果支持修改、删除和被后续多次报告选择使用。
- [ ] 附件记录名称、大小、存储状态和使用状态；删除人工记录时处理其附件关系。
- [ ] 人工结果修改或删除产生报告过期事件，供报告生命周期消费。
- [ ] 数据库、人工结果与附件接口、独立页面和恢复编辑均有自动化测试。

## 2026-10-28 状态校准

- 已有：按测试组批次保存/恢复/修改/删除人工结果、用例范围限制、附件记录和报告过期事件的 API 与测试。
- 未完成：冻结版人工结果表格仍使用本地状态；真实批量保存、恢复编辑、附件上传/清理及错误状态尚未在当前入口贯通。
- 结论：后端基础能力已实现，冻结 UI 联调待完成。
