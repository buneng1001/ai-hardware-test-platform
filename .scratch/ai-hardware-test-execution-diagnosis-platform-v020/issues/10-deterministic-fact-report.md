# 10 — 生成不依赖 AI 的模块化事实报告

**What to build:** 让测试工程师选择同一测试组、同一产品版本的一条自动化执行记录和零至多条人工记录，生成可在线查看和下载的模块化事实报告。模型服务或 Skill 完全不可用时仍能交付完整报告。

**Blocked by:** 08 — 执行数据驱动模拟并保存不可覆盖快照；09 — 独立录入并维护人工测试结果。

**Status:** ready-for-agent

**当前前端 Demo 对应页面：** “执行与结果”中的“最终报告”；报告预览和 HTML/纯文字下载按钮。

- [x] 一次最多选择一条自动化记录和多条人工记录；只有其中一类记录时也允许生成。
- [x] 不同测试组或不同产品版本的记录不能合并。
- [x] 报告使用记录历史快照；与当前测试组配置不一致时提示但不阻塞生成。
- [x] 报告依次包含测试基本信息、阶段推进事实依据、AI 区域状态、范围总览、模块详情和跨模块问题。
- [x] 报告按原始用例“模块”字段分组，空模块归入“未分类”，每个模块开头展示有证据支撑的当前事实结论。
- [x] 自动化和人工结果冲突时保留双方记录并标记“结果不一致”。
- [x] 失败、阻塞、人工缺失或 AI 未配置均不阻止事实报告生成。
- [x] HTML 与纯文字版本保持相同的信息顺序和事实结论。
- [x] 数据库报告快照、生成与下载接口、报告页签和确定性内容均有自动化测试。
