# 11 — 接入可选报告分析适配器并提供失败降级

**What to build:** 在事实报告完成后，通过 `ReportAnalysisService` 可选生成结构化风险、补充验证、回归建议和阶段推进建议。未配置适配器或分析失败时，事实报告保持完整可用；具体项目 Skill 不属于 v0.2.0 必须交付项。

本 ticket 只负责前端接线：消费接口返回的状态、原因和重试能力，不负责错误分类质量、截断处理、分批检查点和结果激活。

**Blocked by:** 10 — 生成不依赖 AI 的模块化事实报告

**Status:** ready-for-agent

**当前前端 Demo 对应页面：** 最终报告中的阶段建议和 AI 分析区域；首页 AI 配置。

- [x] AI 输入只来自已保存事实报告和有限支撑数据，不读取无关原始日志或凭空补充阈值。
- [x] 分析输出经过结构化模式校验，不能修改事实状态、测试资产、测试组或数据包。
- [x] 服务支持未启用实现、项目现有模型服务适配器和固定输出 Mock，并保留未来项目定制适配器位置。
- [x] 未配置适配器时显示"AI 分析未启用"；超时、不可用或无有效输出时显示"分析未完成"和简短原因。
- [x] AI 未启用或失败不会回滚、删除或阻止事实报告。
- [x] 用户可以单独重试报告分析，不重新执行自动化测试或重新录入人工结果。
- [x] 阶段推进只表达建议及依据，不实现强制质量门禁。
- [x] 分析运行状态持久化、接口、报告 AI 区域和失败降级均有自动化测试。
- [x] 报告 AI 区域展示失败原因时直接使用接口返回值，前端不自行编造原因，也不把失败显示成成功。
