# 12 — 管理在线报告、过期状态和附件清理

**What to build:** 完成在线报告的覆盖、过期、删除和历史查找规则，并让测试工程师从报告页清理已被当前报告使用的人工附件，而不破坏报告文字事实和底层测试记录。

**Blocked by:** 10 — 生成不依赖 AI 的模块化事实报告。

**Status:** ready-for-agent

**当前前端 Demo 对应页面：** “执行与结果”的报告区域；设计中的“报告与历史记录”页面。

- [x] 测试组成员、数据包关联、再次执行、人工结果修改或删除会将当前在线报告标记为过期。
- [x] 过期报告仍可查看和下载，不会自动改写。
- [x] 重新生成覆盖当前在线报告，但不影响用户已经下载的 HTML 或纯文字副本。
- [x] 删除在线报告不删除自动化执行记录、人工记录或数据包。
- [x] 报告页显示已使用附件的数量、总大小和具体使用状态。
- [x] 清理前展示影响确认，只删除当前报告已使用的原始附件。
- [x] 清理后保留人工文字结果、附件名称和“已清理”状态，未使用附件不受影响。
- [x] 报告与历史记录页可查找自动化记录、人工记录和最终报告。
- [x] 报告与附件状态、生命周期接口、历史页面和删除影响均有自动化测试。
