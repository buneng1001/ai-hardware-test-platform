# 13 — 展示项目趋势并主动比较版本或报告

**What to build:** 在项目详情中根据已生成的最终报告展示历史趋势，并让测试工程师主动选择两个产品版本或两份报告，比较模块、状态和测试范围变化。

**Blocked by:** 12 — 管理在线报告、过期状态和附件清理。

**Status:** ready-for-agent

**当前前端 Demo 对应页面：** “版本与趋势”；项目卡中的报告数量和趋势摘要。

- [ ] 趋势只统计最终报告，不统计准备状态、无报告的执行记录或已删除报告。
- [ ] 支持按产品版本、模块、测试组和测试用例筛选。
- [ ] 展示自动化与人工的通过、失败、阻塞、未执行数量及模块结果变化。
- [ ] 无报告、筛选无结果和只有一个数据点时分别展示正确状态。
- [ ] 过期报告的数据点保留并标记；删除报告后对应数据点移除。
- [ ] 用户必须主动选择两个产品版本或两份报告，系统不默认比较最新和上一版本。
- [ ] 对比明确展示新增、删除及无法对齐的测试范围，不把范围缺失解释为通过或失败。
- [ ] 数据库聚合查询、趋势与对比接口、项目详情页面和统计边界均有自动化测试。
