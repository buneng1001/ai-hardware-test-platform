# 01 — 建立可运行的洁净工程骨架

**What to build:** 让测试工程师能够在本机启动前后端，打开平台状态页，并通过公开 API 验证服务与本地数据库可用，形成后续垂直切片都能复用的最小运行和测试基线。

**Blocked by:** None — can start immediately

**Status:** claimed

- [ ] FastAPI 后端、React/TypeScript 前端和 SQLite 可按统一说明在本机启动，前端使用 pnpm 管理依赖。
- [ ] 浏览器能显示后端健康状态，公开健康 API 和前端页面均有外部行为测试。
- [ ] Pytest、前端测试、格式检查和 GitHub Actions Mock 基线可运行，并区分代码、环境、依赖和沙箱错误。
- [ ] 建立 UTF-8、换行、忽略文件、环境变量示例、项目内数据目录和敏感信息检查基线。
- [ ] 仓库不包含真实密钥、公司资产或旧项目内容，日志和示例配置不泄露敏感信息。
- [ ] 更新课程映射的工程骨架与 CI 状态及证据；工程日志记录真实搭建问题和验证；面试案例只补充已验证的启动与安全基线。
