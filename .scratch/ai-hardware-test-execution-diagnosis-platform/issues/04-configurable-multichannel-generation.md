# 04 — 扩展可配置的多通道合成文件生成

**What to build:** 让测试工程师通过界面配置完整的数据参数，生成 1～4 路视频和对应传感器文件，并用固定随机种子验证产物可重复，同时安全控制文件规模。

**Blocked by:** 03 — 生成正常场景文件并跑通首个运行记录

**Status:** claimed

- [ ] 支持快速、标准和自定义模式，以及规格规定的时长、通道数、分辨率、帧率、容器、IMU 格式和采样率。
- [ ] 视频使用 H.264，IMU 支持 CSV 和 JSONL，设备状态与日志随运行一起生成。
- [ ] 固定随机种子的重复运行产生相同哈希或等价指标，并能查看用于验证的产物元数据。
- [ ] 长稳趋势使用虚拟时间，报告和产物元数据明确区分实际生成与虚拟时间模拟。
- [ ] 参数边界、非法组合和文件大小保护通过前后端及 API 主 seam 验证。
- [ ] 更新课程映射中的数据驱动、边界值和文件处理证据；工程日志记录真实性与速度取舍；面试案例只补充已验证的多通道生成能力。
