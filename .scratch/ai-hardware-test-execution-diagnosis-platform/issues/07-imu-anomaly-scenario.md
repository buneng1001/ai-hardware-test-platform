# 07 — 交付 IMU 异常场景

**What to build:** 让测试工程师从界面运行固定种子的 IMU 异常场景，并查看丢样、重复、时间戳倒退和间隔分布的确定性检测及故障真值对照。

**Blocked by:** 04 — 扩展可配置的多通道合成文件生成

**Status:** claimed

- [ ] 场景在生成前记录 IMU 丢样、重复、时间戳倒退的故障真值与预期检测结果。
- [ ] IMU 检查覆盖采样率、丢样、重复、倒退和采样间隔分布，并输出统一检测结果。
- [ ] 运行详情或分析视图展示每类异常的指标、位置和故障真值对照。
- [ ] CSV 与 JSONL 均有契约测试，固定种子可重复，正常场景不误报。
- [ ] API 主 seam 验证场景执行、检测命中和结果展示。
- [ ] 更新课程映射中的 IMU 检查、数据驱动和参数化测试证据；工程日志记录真实传感器数据问题；面试案例只补充已验证的 IMU 检测能力。
