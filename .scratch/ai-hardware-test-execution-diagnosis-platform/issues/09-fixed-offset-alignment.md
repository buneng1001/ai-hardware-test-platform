# 09 — 交付固定偏移时间对齐

**What to build:** 让测试工程师选择参考时钟，对多通道原始时间戳执行固定偏移校正，并同时看到对齐前指标、校正参数和对齐残差。

**Blocked by:** 04 — 扩展可配置的多通道合成文件生成

**Status:** ready-for-agent

- [ ] 合成数据允许各通道具有不同起点、固定偏移和抖动，并保留原始时间戳。
- [ ] 默认使用第 1 路相机作为参考时钟，同时允许测试工程师选择其他通道。
- [ ] 系统根据共同事件估计固定偏移，保存校正方法、参数和独立的对齐后结果。
- [ ] 分析视图同时展示对齐前偏移、抖动以及对齐后残差，校正结果不覆盖原始证据。
- [ ] 已知偏移的契约测试与 API 主 seam 验证参数估计和可观察结果。
- [ ] 更新课程映射中的时间分析和契约测试证据；工程日志记录真实对齐问题；面试案例只补充已验证的固定偏移校正能力。
