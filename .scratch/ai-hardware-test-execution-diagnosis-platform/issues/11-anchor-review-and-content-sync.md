# 11 — 支持锚点复核与内容同步独立评价

**What to build:** 让测试工程师查看和调整跨模态锚点，并分别审查时间戳对齐和画面内容同步，避免把时间接近误判为内容同步。

**Blocked by:** 10 — 交付线性漂移时间对齐

**Status:** claimed

- [ ] 系统自动识别视频时间码或跑马灯事件以及 IMU 冲击峰值，并建立稳定锚点引用。
- [ ] 测试工程师可查看、调整或排除锚点，重新计算后保留使用的锚点与参数。
- [ ] 分析视图分别展示时间戳对齐结果和画面内容同步结果。
- [ ] 锚点误识别、缺失和人工调整具有可理解的错误或降级行为。
- [ ] API 主 seam 和关键 UI 流程验证锚点调整会产生新的可观察分析结果且不覆盖原始证据。
- [ ] 更新课程映射中的 UI 流程与同步分析证据；工程日志记录真实锚点问题；面试案例只补充已验证的复核与双重评价能力。
