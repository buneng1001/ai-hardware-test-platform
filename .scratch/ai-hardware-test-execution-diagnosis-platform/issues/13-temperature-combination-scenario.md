# 13 — 交付温升关联组合故障场景

**What to build:** 让测试工程师运行温度升高后视频掉帧和 IMU 丢样的组合场景，并从同一时间窗口审查资源、日志和多个确定性检测结果。

**Blocked by:** 06 — 交付单路视频掉帧场景；07 — 交付 IMU 异常场景

**Status:** claimed

- [ ] 场景在生成前记录温升、掉帧、丢样的故障真值、注入窗口和预期检测结果。
- [ ] 系统生成相互一致的温度趋势、视频异常、IMU 异常和设备日志。
- [ ] 检查结果将视频、IMU、资源和日志证据关联到同一异常时间窗口，但不把相关性宣称为根因。
- [ ] 分析视图展示多个确定性事实、稳定证据引用和故障真值对照。
- [ ] API 主 seam 验证固定种子可重复且所有预期检查命中。
- [ ] 更新课程映射中的组合故障和跨证据分析证据；工程日志记录真实关联问题；面试案例只补充已验证的组合故障能力。
