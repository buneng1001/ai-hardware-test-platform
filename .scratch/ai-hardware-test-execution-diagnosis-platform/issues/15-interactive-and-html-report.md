# 15 — 交付应用内报告与独立 HTML

**What to build:** 让测试工程师在一个分析报告中审查完整运行事实，并导出无需平台即可打开的 HTML 报告。

**Blocked by:** 05 — 支持排队、取消、重新执行与异常中断识别；06 — 交付单路视频掉帧场景；07 — 交付 IMU 异常场景；08 — 交付存储不足与提前停止场景；11 — 支持锚点复核与内容同步独立评价；12 — 交付三种判定模式；13 — 交付温升关联组合故障场景；14 — 录入和导入人工检查结果

**Status:** ready-for-agent

- [ ] 应用内报告统一展示配置快照、运行阶段、产物来源、检测结果、故障真值对照、时间分析、判定依据和人工结果。
- [ ] 报告清楚区分检测结果、人工检查结果、故障真值和尚未生成的诊断结论。
- [ ] 图表和指标能表达对齐前后结果、异常时间窗口和三种判定模式，不依赖页面内部实现测试。
- [ ] 导出的 HTML 可在脱离应用和数据库的环境中打开，并保持关键内容可读。
- [ ] API 主 seam 和关键 UI 流程覆盖报告读取、导出、缺失可选数据和异常运行。
- [ ] 更新课程映射中的报告、UI 自动化和主 seam 证据；工程日志记录真实渲染或导出问题；面试案例只补充已验证的报告能力。
