## Answer

- **实现**：新增 `backend/app/siliconflow.py` 独立适配层、`backend/app/settings.py` 设置/连接测试 API；诊断 API 支持 Mock 和硅基流动模式，真实输出复用结构化 Schema 与证据引用校验。
