# 18 — 接入硅基流动并实现安全降级

**What to build:** 让测试工程师安全配置并测试硅基流动连接，在本地请求真实结构化诊断，同时保证模型错误不会阻断确定性测试和原始报告。

**Blocked by:** 17 — 交付 Mock AI 结构化诊断

**Status:** ready-for-agent

- [ ] 模型调用通过独立适配层完成，诊断业务不依赖硅基流动的服务商细节。
- [ ] 设置页支持是否已配置、连接测试、Mock 切换和会话内临时输入，后端不返回 Key 或掩码值。
- [ ] 诊断运行保存模型、Prompt 版本、生成时间、Mock 状态、输入摘要、输出状态和错误，但不保存 Key。
- [ ] 只对超时、限流和临时服务错误最多自动重试两次，其他错误直接保存并允许人工重试。
- [ ] 模型不可用时运行记录仍可完成、查看和导出原始报告，诊断状态独立显示失败或待生成。
- [ ] 适配层契约测试覆盖成功、错误分类、重试边界、结构校验和敏感信息过滤；CI 不调用真实模型。
- [ ] 更新课程映射中的 AI 接口联调、重试和降级证据；工程日志记录真实服务问题；面试案例只补充已验证且不泄密的真实诊断能力。
