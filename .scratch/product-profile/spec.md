# V0.3.0｜02 项目级产品画像完善详细 Spec

> 状态：详细 Spec 已确认并冻结（V0.3.0 To Spec 整体仍在进行）。字段、编辑入口、运行中画像快照规则及接口快捷标签目录均已确认。尚未实现，不进入 To Tickets。

## 1. 目标与已确认范围

- 复用 V0.2.0 新建项目时已有的产品画像字段、默认值、校验与项目级存储，不新建画像业务表、不增加版本级画像覆盖。
- 已有项目补齐「编辑产品画像」入口，读取当前已保存值，支持修改、保存、取消；不改变项目名称、产品名称、版本及用例等其他业务信息。
- 新建项目原画像表单和流程保持不变。所有项目版本共享该项目的当前默认画像。
- 画像编辑不改写历史报告快照、历史分析、既有测试事实及已保存业务结果；不自动重跑 AI 或重新生成报告。
- 03–07 本版仅 UI；通过需求文字补充产品变化的真实分析链路属于未来开发范围，本期不实现。

## 4. 编辑与保存（已确认原则）

- 打开编辑时读取目标项目当前已保存画像；使用独立表单草稿，未保存不改写项目。
- 保存通过现有更新接口提交完整画像；成功后以返回的 ProjectDetail 更新项目列表/详情，重新打开或刷新后显示实际保存值。
- 取消不发起保存请求；校验失败或请求失败时保留草稿、明确显示错误，不伪装成功。
- 历史项目画像为 null 时，编辑表单可回显既有默认值；在用户明确保存前不写入数据库，不将缺失画像冒充真实硬件信息。
- 不要求 AI 开启即可编辑产品画像；该功能是项目基本信息维护。

## 5. 编辑入口、运行中修改与接口快捷输入

### 5.1 编辑入口（已确认）

- 项目列表卡片「更多」菜单中增加「编辑产品画像」，与现有「删除项目」并列；不增加项目工作区导航项或独立页面。
- 点击后打开产品画像编辑弹窗，复用新建项目时的画像字段和视觉语言；显示当前项目标识及已保存画像。
- 提供「保存」「取消」；取消不提交；保存成功后立即更新项目列表/详情展示。
- 新建项目时填写画像的既有流程不变，仍要求用户在创建时填写。

### 5.2 画像修改与 AI 运行（已确认）

- 产品画像是项目当前默认画像。用户任何时候都可以编辑并保存，包括该项目有 AI 业务调用正在运行时；画像保存不受 AI 运行锁阻止。
- 若当前项目有正在运行且已读取画像的 AI 任务，用户保存前显示提示：**「当前有 AI 任务正在运行，本次修改无法更新已经生成的内容及本次任务后续批次，将在下一次发起相关 AI 操作时生效。」** 用户确认后仍正常保存，不要求停止任务、不等待任务结束。
- 每次 AI 业务调用在启动时读取并冻结项目画像快照；该调用的所有批次继续使用同一快照，不在批次之间切换新旧画像。保存新画像只影响之后新发起、需要读取项目画像的 AI 调用。
- 若当前运行任务属于其他项目，或该任务不读取产品画像，不显示会误导用户的运行中画像提示；保存照常进行。
- 画像变化不自动触发重新分析、重新转换、重新生成报告或覆盖任何结果。历史分析和报告继续使用生成时保存的快照；再次查看或分析既有报告时，不得以当前画像改写历史测试事实。
- 若分批任务因中断/失败/取消留下检查点，画像已变化后，旧检查点的输入指纹不再匹配；不得将旧画像任务的检查点续接到新画像输入。用户可按 01 既定规则选择重新运行，或保留原结果。

### 5.3 通信接口快捷输入（已确认）

- 保留现有 `interfaces` 单一字符串字段和现有 API 数据契约，不新增数据库字段、不将其改为枚举或多对多关系。
- 输入框位于上方，快捷标签按类别放在输入框下方。点击一个预设标签，将其文字追加到输入框当前内容中，使用「、」分隔；不清空、不覆盖用户已输入的自定义内容。
- 标签只提供快捷输入，不限制用户填写范围。用户始终可以直接输入、编辑、删除任意文字，也可以混合使用预设与自定义内容。
- 已经存在于输入框的标签再次点击不得重复追加；删除内容由用户直接编辑输入框完成。
- 类别用于帮助用户发现可填写的接口范围，分为常用接口、有线/物理连接、无线通信、调试/控制与板级总线。完整预设目录见第 5.4 节。
- 当前前端新建项目表单的接口输入 `maxLength` 为 100，后端 `ProductProfile.interfaces` 上限为 300。为容纳多个快捷标签，前端新建和编辑表单统一对齐到后端现有 300 字符上限；不改变后端字段约束。

### 5.4 接口快捷标签目录（已确认）

| 类别 | 预设标签候选 |
| --- | --- |
| 常用接口 | USB Type-C、USB-A、Micro-USB、Wi-Fi、Bluetooth、BLE、HDMI、RJ45 以太网、3.5mm 音频 |
| 有线/物理连接 | Lightning、DC 电源接口、PoE、Pogo Pin、SIM 卡槽、SD 卡槽、MicroSD/TF 卡槽、FPC/FFC |
| 无线通信 | NFC、RFID、红外 IR、Zigbee、Thread、UWB、4G LTE、5G、NB-IoT、LoRa/LoRaWAN、GNSS/GPS |
| 调试/控制与板级总线 | UART/TTL 串口、RS-232、RS-485、I2C、SPI、CAN、GPIO、JTAG/SWD、ADB 调试、MIPI CSI/DSI、I2S、PCIe |

- 上述类别和标签是帮助用户发现填写项的候选词，不表示每个产品都具备这些接口，也不要求用户全部选择。
- 按类别分组显示，避免一次性平铺大量标签；保留自由输入和自定义接口能力。用户已确认当前目录，无需追加预设项。

## 6. 验收草案

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| P01 | 新建项目 | 既有画像字段、默认值与创建流程不变 |
| P02 | 打开已有项目画像 | 回显当前保存值，项目身份正确 |
| P03 | 修改并保存 | 现有接口更新指定项目；列表/详情、重新打开及刷新后显示新值 |
| P04 | 修改后取消 | 不写入，旧画像保持 |
| P05 | 无效数据或保存失败 | 不覆盖原画像，保留编辑草稿并提示 |
| P06 | 历史项目无画像 | 编辑时默认值可见；未确认保存前保持 null |
| P07 | 历史报告与事实 | 更新画像后历史快照与既有业务记录不变 |
| P08 | 项目隔离与版本共享 | 只更新当前项目；该项目各版本读取当前默认画像，其他项目不变 |
| P09 | AI 关闭时编辑 | 正常保存，不调用模型 |
| P10 | 编辑入口 | 从项目卡片「更多」打开画像编辑弹窗；保存更新当前项目，取消不写入 |
| P11 | 运行中修改画像 | 当前项目有读取画像的 AI 任务运行时允许保存；显示不会更新本次已生成内容及后续批次的提示；本次任务继续使用旧快照 |
| P12 | 下一次调用生效 | 画像保存后新发起的相关 AI 调用读取新画像；不自动重跑旧任务 |
| P13 | 历史报告快照 | 修改画像后历史报告仍显示原生成时画像，不回写事实 |
| P14 | 画像变更与续做检查点 | 画像修改导致输入指纹变化，旧画像任务检查点不得用于新画像输入续做 |
| P15 | 接口快捷标签 | 点击分类预设后追加到输入框，保留自定义文字、不重复添加；可手动编辑和删除 |
| P16 | 接口字段长度 | 新建与编辑界面允许最多 300 字符，与后端现有约束一致 |

## 7. 本期不做

画像版本库、版本级覆盖、字段扩展、自动影响分析/自动重跑、未来需求文字驱动的画像更新链路。接口快捷标签不改变底层数据结构，也不限制自定义输入。保持 C 方案视觉与现有项目管理页面布局，不减少已有操作。
