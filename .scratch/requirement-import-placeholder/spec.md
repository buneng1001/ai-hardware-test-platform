# V0.3.0｜11 需求导入预留入口及未开发功能提示详细 Spec

> 状态：行为规则已确认。视觉表现暂不冻结，待 UI 实际呈现后结合效果调整。本项只定义占位入口行为，不实现需求导入或 AI 处理能力；尚未进入 To Tickets。

## 1. 目标与范围

V0.3.0 保留未来「测试需求文件导入」的可见入口，使用户知道该能力属于平台规划范围；点击时明确告知功能尚在开发，不启动任何实际处理。

本项是独立人工验收项，必须与 03–07 的 UI 占位规则一致，也不得影响 V0.2.0 已有正式测试用例导入功能。

## 2. 现有实现基线

- `frontend/src/V020RequirementsScreen.tsx` 当前「导入需求点」按钮会触发隐藏的 `input[type=file]`，打开浏览器文件选择器，并在页面本地显示文件名。
- 当前「开始解析」按钮为禁用状态，页面常驻显示「需求点解析尚未接入」说明；这些交互不符合已确认的 V0.3.0 占位入口规范。
- 当前「导入用例」通过既有 `onOpenSource` 流程进入正式测试用例导入，不属于需求文件导入预留入口，必须保留。
- 现有正式测试用例 CSV/XLSX 导入能力不得因本项调整而受影响。

## 3. 入口与交互契约

### 3.1 需求文件导入入口

- 保留「导入需求点」按钮，采用正常产品按钮样式，不置灰、不禁用。
- 点击后只显示一次轻量提示：**「该功能开发中」**。
- 提示关闭或自然消失后停留在当前页面，不清空页面内容、不改变项目/版本、不跳转。
- 点击不得触发隐藏文件输入框，不得打开系统文件选择器。
- 不读取文件、不上传文件、不解析文件、不保存文件名或文件内容，不调用任何导入/解析接口。

### 3.2 相关 AI 分析占位入口

- 如果「开始解析」「AI 分析」等未来功能按钮在 03 的页面 UI 中保留，应保持正常可点击样式。
- 点击只显示同一提示「该功能开发中」，不调用模型、不创建任务、不生成结果、不写入数据。
- 不以禁用按钮或常驻「未接入」文字说明替代点击提示。具体页面结构由 03 的 UI 占位 Spec 管理，本项只统一提示行为。

### 3.3 必须保留的现有功能

- 「导入用例」继续进入现有正式测试用例导入流程。
- 原始测试用例表既有 CSV/XLSX 导入、字段映射、校验、导入记录及错误提示均不因本项改变。
- 不得把「导入用例」误改为占位按钮，也不得将其与未来需求文档导入合并。

### 3.4 与版本级 AI 补充说明的边界

- 本 Spec 中「不读取、不上传、不写入数据」仅约束点击「导入需求点」及其他未来分析占位入口的行为。
- 页面按已确认方案将「导入需求点」「AI 分析」「智能测试用例推荐」等占位入口放在需求材料操作区；「本版本 AI 补充说明」单设真实编辑保存区，两者不混合，也不新增业务页签。
- 「本版本 AI 补充说明」是第 03 项定义的独立真实功能，允许用户编辑并保存到当前产品版本的 `ai_context`；不得因本项导入入口不写入数据而一并禁用或删除该输入框。

## 4. 数据、接口与状态边界

- 本项不新增或调用需求文件导入 API、文件上传 API、文档解析 API、AI 分析 API。
- 不新增数据库表、业务对象、导入批次、文件记录或持久化字段。
- 不写入项目画像、测试需求、需求点、原始用例、自动化候选、测试组或报告。
- 上述不写入限制仅针对本项的需求导入/未来分析占位入口；第 03 项的 `ai_context` 输入框是独立真实功能，按其详细 Spec 正常保存。
- 点击提示不创建 AI invocation，不占用全局 AI 调用名额，不受 AI 全局开关影响。
- 提示属于纯 UI 反馈；关闭后页面保持原状。重复点击可以再次提示，不做队列、不做延迟任务。

## 5. 异常与边界

- 浏览器不应出现文件选择器；因此用户取消文件选择、文件格式不支持、文件读取失败等文件处理分支均不属于本项。
- 若提示组件异常，不得回退为文件选择或模拟导入成功；页面其余现有功能保持可用。
- 若用户点击「导入用例」，仍按正式用例导入流程处理，与本项提示逻辑隔离。

## 6. 独立人工验收

| 编号 | 场景 | 操作 | 明确预期 |
| --- | --- | --- | --- |
| I11-01 | 入口外观 | 打开「测试需求」页签 | 「导入需求点」以正常可点击按钮显示，不是灰色禁用状态 |
| I11-02 | 点击需求导入 | 点击「导入需求点」 | 只显示「该功能开发中」；不打开文件选择器、不跳转 |
| I11-03 | 无文件副作用 | 点击需求导入并观察浏览器行为/网络请求 | 不读取文件、不上传、不调用导入或解析 API、不保存文件名或文件内容 |
| I11-04 | 无业务写入 | 点击需求导入后刷新页面并检查业务数据 | 不新增需求、需求点、用例、导入批次或其他业务记录 |
| I11-05 | 相关 AI 入口 | 点击页面保留的「开始解析 / AI 分析」按钮 | 只显示同一提示；不调用模型、不创建 AI 任务、不生成结果 |
| I11-06 | 提示关闭 | 关闭提示或等待提示消失 | 留在原页面，页面已有数据和状态不变 |
| I11-07 | 正式用例导入回归 | 点击「导入用例」，执行既有 CSV/XLSX 导入 | 原有正式测试用例导入完整可用，字段映射、校验和导入结果不受影响 |
| I11-08 | 重复点击 | 连续再次点击需求导入入口 | 每次仅显示提示，不累计任务、不产生延迟动作 |

## 7. 自动化测试与回归范围

- 前端组件测试：点击需求导入只显示提示；断言隐藏文件输入框未触发、文件选择回调未执行。
- 网络/服务 Mock 测试：断言需求导入和 AI 分析占位按钮不发起请求、不创建 invocation。
- 持久化回归：确认点击入口前后没有新增需求导入、需求点或其他业务记录。
- 既有导入回归：运行正式测试用例 CSV/XLSX 导入相关组件与 API 测试，确认「导入用例」行为未被替换。
- 页面回归：确认提示不改变路由、项目、版本及当前页面数据。

## 8. 不做事项

需求文件选择、读取、上传、格式识别、解析、需求文本保存、AI 需求分析、AI 风险分析、AI 用例推荐、需求审核、用例审核、导入批次管理，以及任何相关真实后端 API 或数据库能力。未来版本待重新规划。
