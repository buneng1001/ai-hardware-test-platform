## 关键风险及依赖说明

- **AI 配置风险**：现有连接测试调用 save_selection，会误切正式配置；T01 阻塞 T02。
- **取消边界**：底层模型请求尚未返回/超时时仍占全局锁，T03 和业务域 T04–T06 完成后才能验收 T09。
- **上下文冻结**：T11 必须先落库，T04–T06/T15 启动读取并冻结当前版本 ai_context；T10 项目画像编辑可独立推进。
- **最终报告来源**：T13 明确无和历史报告快照后，T14 才能依据真实主报告嵌入报告 ID 排重。
- **建议质量与替换**：T15 先严格证据/结构校验，T16 成功提交后唯一当前建议原子替换。
- **正式资产一致性**：T18–T21 依次建立人工、自动化、测试组、逐条幂等失败补偿；人工审核不等于自动化技术校验。
- **关联查询**：数据库已支持一对多，但来源 API 当前只显示一条；T22 全量计数之后 T23 双向来源链接；九列和旧功能保真。
- **范围风险**：04–07/11 不实现需求→风险→推荐→审核发布真实链路；09 附件继承取消但旧证据上传/查看/下载保留。
