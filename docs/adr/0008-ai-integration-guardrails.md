# AI 接入采用分级验收与运行快照护栏

AI 能力按"已发现、已验证、业务流程已验收"三级分别记录和展示，任何一级都不得代替下一级；每次 AI 运行绑定不可变配置快照（provider、Endpoint、模型、密钥来源、网络模式、Prompt 版本），任一字段变化立即使旧验证失效。长输入按语义单位分批并逐批保存检查点，输出截断按事实报告并允许二分降级，结构化失败先做本地确定性归一化、最多允许一次受约束模型修复。这样做的原因是：最小请求成功不能证明业务可用，旧验证状态和单一超时会把截断误报成接口故障，而这类误判会直接损害作品集的可信度。详细要求见 [AI 接入护栏](../ai-integration-guardrails.md)。

本决定修订 ADR 0006 的重试条款：瞬时错误由"最多两次自动重试"改为"最多重试一次、退避 1 秒并计入调用上限"，鉴权、权限、无效模型和确定性 Schema 失败不重试。ADR 0006 关于"AI 不进入测试执行关键路径"的结论不变。
