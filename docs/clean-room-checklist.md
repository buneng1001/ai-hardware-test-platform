# 洁净重写与发布安全检查

每次公开、导出或合并前执行：

- [ ] 代码、测试、接口、Prompt 和文档均从本仓库独立设计，没有读取或复制任职期间项目内容。
- [ ] 示例只使用虚构设备、公开格式和后续 ticket 生成的确定性合成数据。
- [ ] 不包含公司名称、内部协议、内部接口、截图、日志、数据或产品标识。
- [ ] `.env`、数据库、报告、日志、证书、私钥和原始设备数据未进入 Git。
- [ ] 执行 `python scripts/check_repository_safety.py`，并人工复核自动扫描不能判断的资产来源。

自动扫描只能识别常见密钥形态和高风险文件，不能证明资产权属；洁净来源仍需人工确认。
