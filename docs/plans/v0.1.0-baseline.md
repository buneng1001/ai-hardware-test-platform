# v0.1.0 基础 POC 基线

## 定位

记录当前版本已经完成的基础能力，作为后续版本的稳定基线。当前没有实体被测设备，因此不接入真实硬件。

## 已完成模块

- 采集任务、运行记录、队列、取消、重跑和异常中断恢复。
- 合成或导入视频、IMU、设备状态和日志数据。
- 视频、IMU、存储、资源和日志确定性检查。
- 固定偏移、线性漂移和跨模态事件对齐。
- 人工检查结果、基础 HTML 报告和 ZIP 证据包。
- Mock/硅基流动诊断适配、证据引用校验和安全降级。
- Pytest、Allure 和 GitHub Actions CI 骨架。

## 基线验收

- 六个内置场景可以重复生成和检查。
- 正常场景不误报，故障场景能够命中预期检查。
- 模型不可用时，运行和基础报告仍然完成。
- 报告、证据包、测试结果和 CI 产物可以独立复查。

## 明确不包含

测试前 AI 用例推荐、项目/测试组完整治理、ADB/HTTP/Shell 设备控制、音频、Jenkins 和企业级版本准入。
