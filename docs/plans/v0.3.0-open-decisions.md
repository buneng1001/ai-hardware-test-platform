- 详细 Spec 先记录可执行的推荐值或暂定口径，并标明「待统一确认」，不因单个细节反复中断逐项评审。

- 在全部 Spec 完成后集中讨论；用户确认后回写对应详细 Spec、总体 Spec 和本清单。
- 本文件与 [后续开发计划项](future-development-items.md) 不同：前者是当前 V0.3.0 范围内待拍板的细节，后者是当前版本明确不做的未来功能。
