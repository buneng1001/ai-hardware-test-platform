# v0.5.0 音频与多模态分析

## 目标

在视频、IMU、设备状态和日志基础上加入音频，并统一管理多模态数据的时间、格式、质量和关联证据。

## 数据格式

| 模态 | 首选格式 | 后续兼容格式 |
| --- | --- | --- |
| 视频 | MP4/H.264 | MKV/H.264、H.265 |
| IMU | CSV | JSONL、Parquet、MCAP |
| 音频 | WAV/PCM | FLAC、AAC、Opus |
| 设备日志 | JSONL | 纯文本、CSV |
| 资源指标 | CSV | JSONL、Prometheus |
| 事件元数据 | JSON | YAML、SQLite |

## 功能模块

- 音频采集、采样率、声道、时长和编码检查。
- 静音、断续、削波、噪声和音频丢失检查。
- 音频事件与视频帧、IMU 峰值和设备日志的时间对齐。
- 多模态异常窗口和关联证据展示。
- 多模态证据包大小控制、脱敏和报告导出。
- 音频与视频/IMU/资源异常的组合场景。

## 开发任务

1. 扩展产物 Schema 和导入清单。
2. 实现 WAV/PCM 和 FLAC 生成、导入及质量检查。
3. 增加音频事件检测和跨模态锚点。
4. 扩展确定性检查、证据包和报告页面。
5. 增加音频异常组合场景和回归测试。

## 验收标准

- 音频缺失、采样率错误、静音和断续可以被独立检测。
- 音频事件可以与视频、IMU 和日志对齐。
- 关联结果保留原始证据和时间窗口，不把相关性直接宣称为根因。
- 音频进入报告和证据包时符合大小、安全和格式约束。
