# v1.0.0 真实设备与企业级版本准入

## 目标

将本地模拟测试 POC 扩展为可以连接真实设备、执行版本回归并参与企业 CI/CD 准入的测试平台。

## 功能模块

### 真实设备适配

- 设备发现、连接管理、能力探测和版本识别。
- 真实 ADB/HTTP/Shell/串口适配器。
- 固件、应用和设备配置的兼容性矩阵。
- 真实视频、IMU、音频、资源和日志采集。

### 回归测试治理

- 按版本变更、风险、历史失败和覆盖率选择回归用例。
- 对比版本间结果、异常趋势和质量门禁变化。
- 失败后自动生成复测任务和回归候选。
- 保存测试、报告、设备版本和证据包的完整关联。

### 企业 CI/CD

- GitHub Actions 正式质量门禁。
- Jenkins 对照流水线。
- 使用 self-hosted runner 或设备测试 Agent 访问局域网和专用设备。
- 将测试结果和证据包回传报告服务。
- 通过则准入，失败则阻断发布并保留原因。

### 安全与治理

- 凭据隔离、权限控制和审计记录。
- 设备命令白名单和危险操作保护。
- 原始数据、日志、报告和模型输入的脱敏。
- 测试任务、用例、数据集和报告版本化。

## 推荐执行架构

```text
GitHub Actions/Jenkins
  → 调度 self-hosted runner 或设备测试 Agent
  → Agent 执行用例并控制真实设备
  → 上传结构化结果和证据包
  → 报告服务汇总并执行质量门禁
  → 返回准入或阻断结果
```

## 验收标准

- 同一份用例可以在模拟设备和真实设备适配器上执行。
- 真实设备测试的每一步控制、返回值、日志和采集证据可追溯。
- CI 可以根据确定性结果执行版本准入，模型不可用不改变正式检查结论。
- 回归测试、报告、设备版本和发布结果可以完整关联。
